⚠️ 重要提示： PyTorch不支持Pyodide（浏览器Python环境）。
本版本使用ONNX Runtime Web进行推理。

使用步骤：
1. 使用 export_to_onnx.py 脚本将DeePMD模型导出为ONNX格式
2. 上传或提供ONNX模型的URL
3. 输入分子配置并计算

📦 模型转换

导出模型为ONNX格式：
python export_to_onnx.py your_model.pth -o model.onnx

然后将 model.onnx 放在与此HTML文件相同的目录中，或提供可访问的URL。
